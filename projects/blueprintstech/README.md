# BluePrints — Certificate Courses Website

A responsive certificate-course website for **The BluePrints**, designed to present professional and legal education programs and make enquiries easy through WhatsApp and email.

## Live Website

- **Live:** https://blueprintstech.netlify.app/

## Highlights

- Responsive navigation and mobile menu
- Light/dark theme toggle
- Animated hero carousel
- Course cards and certificate gallery
- Image preview modal
- Contact/enquiry form
- WhatsApp and email enquiry actions
- Phone copy-and-call interaction
- Smooth scrolling and reveal animations
- Tailwind CSS via CDN
- Font Awesome and Material Icons

## Tech Used

HTML5 · Tailwind CSS · JavaScript · Font Awesome · Material Icons
